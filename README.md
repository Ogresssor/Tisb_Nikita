# Tisb_Nikita — учебные работы, 5 семестр

Репозиторий с выполненными заданиями по дисциплинам 5 семестра.
Каждый предмет — отдельная папка, внутри — отдельная папка на каждую контрольную точку (КТ),
чтобы задания разных предметов не смешивались.

## Структура

| Папка | Дисциплина | Статус |
|---|---|---|
| [`databases/`](databases/) | Базы данных (преп. Федоров И.А., 4 КТ) | в работе |
| [`math-analysis/`](math-analysis/) | Математика (математический анализ) | не начато |
| [`probability-statistics/`](probability-statistics/) | Теория вероятности и математическая статистика | не начато |
| [`self-development/`](self-development/) | Основы саморазвития, самообразования и самоорганизации | не начато |
| [`communications/`](communications/) | Основы эффективных коммуникаций | не начато |

## Соглашения

- `materials/` — исходники задания: PDF с требованиями, скриншоты личного кабинета.
- `solution/` — файлы решения, которые сдаются на проверку.
- `ZADANIE.md` — текст задания своими словами + что именно требуется сдать.

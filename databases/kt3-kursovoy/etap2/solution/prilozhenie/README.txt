ИНФОРМАЦИОННАЯ СИСТЕМА «КИНОТЕАТР»
Курсовой проект по дисциплине «Базы данных»

================================================================
1. СОСТАВ ПРОЕКТА
================================================================

kinoteatr.py          — программа (Python, оконный интерфейс tkinter)
kino_schema.sql       — скрипт создания таблиц, ключей, ограничений,
                        индексов и представлений
kino_dannye.sql       — скрипт заполнения таблиц контрольными данными
kinoteatr.db          — готовый файл базы данных SQLite (заполнен)
proverka_raboty.py    — сценарий автоматической проверки работы программы
zapusk.bat            — запуск программы в Windows двойным щелчком

================================================================
2. ЧТО НУЖНО ДЛЯ ЗАПУСКА
================================================================

Установленный Python версии 3.8 или новее (https://python.org).
Дополнительные библиотеки НЕ требуются: tkinter (интерфейс) и sqlite3
(база данных) входят в стандартную поставку Python.

При установке Python в Windows нужно отметить галочку
«Add Python to PATH».

================================================================
3. КАК ЗАПУСТИТЬ
================================================================

Способ 1. Двойной щелчок по файлу zapusk.bat

Способ 2. Открыть командную строку в папке с проектом и выполнить:
    python kinoteatr.py

Все файлы должны лежать в одной папке.

Если файла kinoteatr.db в папке нет, при первом запуске программа
создаст базу данных сама из скриптов kino_schema.sql и kino_dannye.sql.

================================================================
4. СТРУКТУРА БАЗЫ ДАННЫХ
================================================================

8 таблиц:
  zhanr       — жанры фильмов (10 записей)
  film        — фильмы (12 записей)
  film_zhanr  — жанры фильмов, связующая таблица для связи «многие
                ко многим» (24 записи)
  zal         — залы кинотеатра (10 записей)
  seans       — сеансы расписания (20 записей)
  klient      — клиенты (12 записей)
  sotrudnik   — сотрудники (10 записей)
  bilet       — билеты (25 записей)

Вычисляемые столбцы:
  zal.vsego_mest       — вместимость зала: ряды × места в ряду
  bilet.itogovaya_cena — цена билета с учётом скидки клиента

Представления:
  v_raspisanie    — расписание сеансов с названиями фильма и зала
  v_seans_svodka  — продано билетов, выручка и заполненность по сеансам

================================================================
5. ВОЗМОЖНОСТИ ПРОГРАММЫ
================================================================

Вкладка «Сеансы»
  Расписание сеансов, отбор по дате, добавление, изменение и удаление
  сеансов. Фильм и зал выбираются из выпадающих списков. Два сеанса
  в одном зале на одно время назначить нельзя.

Вкладка «Продажа билетов»
  Продажа билета: выбирается сеанс, клиент (или «без карты»), кассир,
  ряд и место. Цена считается автоматически с учётом скидки клиента.
  Одно место на сеанс дважды не продаётся. Кнопка «Свободные места»
  показывает занятые места и количество свободных. Возврат билета
  меняет его статус.

Вкладки «Фильмы», «Залы», «Клиенты», «Сотрудники», «Жанры»
  Справочники: просмотр, поиск по нескольким полям, добавление,
  изменение и удаление записей.

Вкладка «Отчёты»
  1. Расписание сеансов на дату
  2. Заполненность залов и выручка по сеансам
  3. Выручка за период
  4. Рейтинг фильмов по числу проданных билетов
  5. Продажи по кассирам
  6. Фильмы по жанру

================================================================
6. ПРОВЕРКА РАБОТЫ
================================================================

Файл proverka_raboty.py выполняет девять проверок: продажу билета,
попытку продать занятое место, выход за размеры зала, просмотр
свободных мест, возврат билета, поиск по справочнику, построение всех
отчётов, добавление и удаление записи, попытку удалить зал, на который
назначены сеансы.

Запуск проверки:
    python proverka_raboty.py

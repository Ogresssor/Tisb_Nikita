# КТ1 — Контрольная работа по дисциплине «Базы данных»

- Тип КТ: контрольная работа
- Количество вопросов: 1
- Отведено времени: 168 ч

## Вопрос 1

Спроектировать структуру базы данных **«Страховая компания»**, содержащую сведения
о клиентах, сотрудниках и договорах компании.

**Задание 1.** Создать инфологическую модель, описывающую БД в терминах таких понятий,
как «сущность», «набор объектов», «связи сущностей и наборов объектов».

**Задание 2.** Трансформировать инфологическую модель в схему реляционной БД,
использующей понятие отношения. Полученная схема используется для заполнения БД
информацией — построения экземпляра БД.

## Требования к оформлению ответа (из прикреплённого PDF)

> В качестве ответа по контрольной работе необходимо прислать на проверку текстовый файл,
> содержащий выполненные задания — этап проектирования и спроектированную инфологическую
> модель, и спроектированную схему реляционной БД со связями между таблицами по конкретным полям.

Итого в файле ответа три части:

1. **Этап проектирования** — предметная область, границы задачи, сущности, атрибуты, бизнес-правила.
2. **Инфологическая модель** — ER-модель: сущности, наборы объектов, связи с указанием типа (1:1, 1:М, М:М).
3. **Схема реляционной БД** — отношения, первичные и внешние ключи, связи между таблицами
   по конкретным полям, нормализация, экземпляр БД.

# КТ1 — контрольная работа по теории вероятностей, вариант 8

## Условия задач

1. Студент разыскивает нужную ему формулу в трёх справочниках. Вероятность того, что формула
   содержится в первом, втором, третьем справочниках, равна 0,6; 0,7; 0,8. Найти вероятность
   того, что формула содержится: только в одном справочнике; хотя бы в одном справочнике.
2. В одном из районов республики 24 человека обучаются на заочном отделении института:
   6 человек на юридическом факультете, 12 — на экономическом, 6 — на налоговом. Вероятность
   успешной сдачи экзамена для юрфака 0,6; для экономического 0,76; для налогового 0,8.
   Найти вероятность того, что наудачу выбранный студент, успешно сдавший все экзамены,
   будущий «налоговик».
3. В партии из 10 деталей имеется 8 стандартных. Наудачу взято две детали. Найти закон
   распределения случайной величины X — числа стандартных изделий в выборке; записать ряд
   распределения, построить многоугольник распределения и функцию распределения.
4. Непрерывная случайная величина X задана функцией распределения F(x) = 0 при x < 0;
   F(x) = A(x − ½·sin 2x) при 0 ≤ x ≤ π; F(x) = 1 при x > π. Найти параметр A, плотность f(x),
   M[X] и D[X], вероятность P(0 ≤ X ≤ π/2).
5. Случайная величина X распределена по нормальному закону, M[X] = 10, σ = 5. Найти
   симметричный относительно математического ожидания интервал, в который попадёт измеренное
   значение с вероятностью 0,9544.
6. Какова вероятность того, что из 100 наугад отобранных монет число монет, лежащих «гербом»
   вверх, будет от 45 до 55?
7. Из генеральной совокупности извлечена выборка с вариантами xᵢ = 1, 2, 3, 4 и частотами
   nᵢ = 23, 25, 27, 25. Найти объём выборки, выборочную среднюю, выборочную дисперсию
   и выборочный стандарт.

## Требования к оформлению

1. Работа предоставляется в электронном виде одним файлом в формате Word.
2. Формулы набираются встроенными средствами Word.
3. Перед решением каждой задачи записывается её условие.
4. Решение сопровождается подробными комментариями, ссылками на формулы и теоремы.
5. Графики и чертежи — с обозначением осей и единиц масштаба.
6. Онлайн-калькуляторы не допускаются.
7. В конце — список литературы.

## Ответы

| Задача | Ответ |
|---|---|
| 1 | только в одном — 0,188; хотя бы в одном — 0,976 |
| 2 | 20/73 ≈ 0,274 (полная вероятность P(A) = 0,73) |
| 3 | P(0) = 1/45; P(1) = 16/45; P(2) = 28/45; M[X] = 1,6 |
| 4 | A = 1/π; f(x) = (2/π)·sin²x на [0; π]; M[X] = π/2 ≈ 1,571; D[X] = π²/12 − 1/2 ≈ 0,322; P = 0,5 |
| 5 | интервал (0; 20), ε = 2σ = 10 (правило двух сигм) |
| 6 | ≈ 0,683 (интегральная теорема Муавра — Лапласа) |
| 7 | n = 100; x̄ = 2,54; Dв = 1,2084; σв ≈ 1,099 (исправленная s² ≈ 1,221) |
